# 大陆 QQQ 平替 QDII 反老鼠仓与防漂移核查清单

当中国大陆场外纯被动纳指 100 QDII 限购 5~10 元/日、且场内纳指 ETF 溢价超过 `+2%` 时，遵循以下四道防线甄选和审核平替 QDII。

## 1. 确定性量化底线（由 `wealth-radar qdii-check` 自动计算）
- **物理防老鼠仓底线**：最新季报前十大重仓中，纯美股/发达市场大盘股（NVDA / AAPL / MSFT / GOOG / AMZN / META / AVGO / ASML / TSM 等）占比 **≥ 65%**。国内公募基金经理在物理上无法对千亿~万亿美元级美股龙头实施老鼠仓坐庄。
- **防风格漂移红线**：前十大重仓中 **A 股 + 港股合计占比 ≤ 20%**（严防挂“全球科技”名义塞入大量 A 股光模块或港股消费/汽车的漂移基）。
- **相关性验证**：过去 120 个交易日真实单位净值日收益率与 `QQQ` 的相关系数 **≥ 0.65**（兼容 T+0/T+1 净值时差）。
- **流动性红线**：名称严禁包含 `持有期`、`定开`、`封闭`、`美元`、`港元`。
- **场内 ETF 溢价红线**：仅当场内纳指 ETF（513100 / 159941 / 159659 / 159501 / 513300）实时溢价率 **≤ +2.0%** 时，才允许考虑场内直接买入；高于 `+2.0%` 一律标红禁止。

## 2. Agent 联网二次尽调清单（CLI 无法覆盖的定性风控）
当 `qdii-check` 选出目标平替基金（如 `021277 广发全球精选C`、`022184 富国全球科技互联网C`、`021842 国富全球科技互联C`）准备投入 ≥ 800 元时，建议联网核查以下 3 点并写入 `web_research_notes`：
1. **基金经理近 6 个月是否发生变更**（防换帅后风格突变）。
2. **基金公司或基金经理近期有无监管处罚/合规负面**。
3. **最新季报/临时公告有无突发限购调整**（核对今日 15:00 前实际可申购上限）。

## 3. 赛道偏离提示（向用户如实披露）
- 若选中的主动 QDII 重仓过度集中于**半导体/光通信硬件**（如美光/台积电/拉姆研究/康宁占比过高，缺少苹果/微软/亚马逊等综合权重），必须在 `bear_case_arguments` 中明确告知用户：**“该标的波动特征更接近费城半导体（SOXX）而非纳指 100（QQQ），下行弹性更大”**。
- 成交后务必通过 `wealth-radar portfolio add-index ... --qdii-code <C类代码> --qdii-holdings-code <主代码>` 入账，以便 Stage 0 在每次新季报披露后自动监测风格漂移。
